# CMMv2

## ビルド方法

### 1. コンパイラのビルド

```bash
make

```

### 2. PL/0 仮想機械のビルド

```bash
cd pl0_vm
make
cd ..

```

## 実行方法

### 1. コンパイル

```bash
./cmm [最適化オプション] [fname.cmm]

```

**最適化オプション:**

* `-o` : 全ての最適化を適用
* `-oB` : 未使用関数の削除
* `-oL` : 連続ラベルの統合
* `-oA` : 定数畳み込み

### 2. 実行

生成された中間コード（`fname.pl`）を指定して実行する。

```bash
./pl0_vm/pl0i [fnameファイル.pl]

```
